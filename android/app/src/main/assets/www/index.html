校园网认证登录

安卓版不做任何系统修改。以下为常见校园网问题的手动处理指引，点击每项展开步骤。
关闭系统代理
检测卡片「系统代理」出现黄色警告时，代理/加速软件的残留设置会导致"登录成功却打不开网页"。
  1. 部分机型：设置 → WLAN → 长按当前网络 → 修改网络 → 代理 → 选择「无」
  2. 检查是否开启了 VPN / 加速器类应用，将其关闭
忘记并重连 WiFi
适用于获取到 169.254.x.x 地址（DHCP 失败）或始终无法连通网关的情况。
  1. 设置 → WLAN → 长按当前校园网 SSID → 忘记网络
  2. 重新点击该 SSID 并输入密码连接
  3. 连接后回到「检测」页重新诊断
打开认证页面登录
App 内登录失败时，可在浏览器中直接打开认证页面手动登录（页面会自动弹出或访问认证服务器地址）。
  1. 连接校园网 WiFi（不认证时打开任何网页通常自动跳转认证页）
  2. 或点击下方按钮直接打开认证服务器页面
检查应用网络权限
Android 17 及以上系统会默认禁止应用访问局域网。若内网相关检测全部失败且提示被拦截：
  1. 设置 → 应用 → 校园网助手 → 权限
  2. 允许「本地网络」权限
  3. 回到「检测」页重新诊断
